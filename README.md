# Mitsuri AI — Android starter

This is the first Android starter for a private multilingual AI assistant.

Included:
- Female-style assistant UI
- Voice input using Android SpeechRecognizer
- Hindi text-to-speech starter
- Chat UI
- Android 8+ support
- No API key hard-coded in the APK

Planned next modules:
1. Secure backend/API gateway
2. Automatic language detection and same-language replies
3. LLM conversation memory with local encrypted storage
4. Reminder/notification system
5. Home-screen widget/shortcut
6. Original Mitsuri-inspired anime avatar and animation
7. Settings for privacy, voice, language and permissions

Important:
The exact Demon Slayer Mitsuri face/voice is not bundled. The avatar should be an original anime character inspired by the requested cheerful aesthetic, and the voice should be a generic female voice rather than an imitation of a specific actor/character voice.

Build:
- Open this folder in Android Studio.
- Let Gradle sync.
- Run on an Android 8.0+ device/emulator.
